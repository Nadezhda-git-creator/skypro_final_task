Git

  • git clone Ссылка с GitHub - скачивает существующий проект (репозиторий) с удаленного сервера (например, с GitHub).
  • git commit -m "Сообщение" - фиксирует добавленные изменения и сохраняет их в истории с понятным комментарием.
  • git status - проверяет статус файлов (показывает измененные, удаленные или новые файлы).
  • git pull - отправляет сохраненные изменения из локального репозитория в удаленный репозиторий (например, на GitHub).
  • git branch Название ветки - создает ветку в локальном репозитории.
